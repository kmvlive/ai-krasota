# @ai-krasota/ui — Дизайн-система

Премиальные токены и компоненты (референсы: Linear.app, Stripe.com — PRD §22.3).
Используется `apps/web` (лендинг платформы, кабинет мастера, сайты салонов).

- `tokens.ts` — палитры, тени, отступы, минимальный touch-target 44px
- `components/` — Button, Card и будущие компоненты конструктора пресетов
